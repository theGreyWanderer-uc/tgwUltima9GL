# Contributing to U9GL

Thanks for considering a contribution. U9GL is **source-available non-commercial copyleft**, not an OSI-approved open-source project. The maintainer offers paid commercial licences.

1. Discuss substantial changes in an issue first.
2. Before submitting code for merging, read and sign [`CONTRIBUTOR-LICENCE-AGREEMENT.md`](CONTRIBUTOR-LICENCE-AGREEMENT.md) using the private method given by the maintainer. Do not publicly upload signed personal details.
3. Confirm you own or are authorised to license what you submit. Contributions produced for an employer, client, or organisation may need written employer permission and an organisational agreement.
4. Do not paste code from Exult, GPL-only software, third-party game executables/assets, or other projects unless the maintainer has reviewed and approved the licensing and provenance.
5. Include tests, a description of changes, and third-party notices where relevant.
6. Acceptance is discretionary. Submitting a pull request alone does not entitle the contributor to a commercial licence or compensation.

**Maintainer contact:** the licensing contact in [README.md, "Licence"](README.md#licence).
